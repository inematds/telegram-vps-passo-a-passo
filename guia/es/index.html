En resumen

Esta guía te muestra cómo configurar, en tu propia VPS, un bot de Telegram que envía tus pedidos a Claude Code mediante tu suscripción. Está pensado para quien tiene un servidor y quiere administrarlo desde el celular sin entregarle a la IA la llave de la casa: solo tú hablas con el bot, la IA solo lee y cualquier cambio espera tu «sí». Son 9 etapas, cada una con el comando, la salida esperada y un Telegram falso para probar. Necesitas una VPS Linux con Python 3, Claude Code con la sesión iniciada mediante tu suscripción y una cuenta de Telegram.

El beneficio

El servidor en tu bolsillo, sin entregar la llave

No necesitas abrir la laptop, conectarte por SSH ni recordar un comando para saber si el disco está lleno. Tampoco tienes que confiar a ciegas en una IA con acceso a la terminal.

Hoy

Laptop, SSH y comandos de memoria

Para ver el espacio disponible o limpiar algunos logs, tienes que estar frente a la computadora, conectarte al servidor y acertar con el comando. O darle acceso total a una IA y cruzar los dedos para que no borre algo que no debía.

Con el bot

Una pregunta en Telegram

«¿Cuánto espacio libre hay?» y te muestra las cifras. «Borra la carpeta logs» y te muestra qué hará, los comandos exactos y «¿Confirmas?». Solo después de tu «sí» cambia algo.

Cómo funciona

Cinco barreras, todas en el código

Ninguna barrera depende de que la IA «obedezca». Cada una es una regla que el programa cumple, incluso si la IA se equivoca o un archivo la engaña.

Tú en Telegram→Lista de propietarios→La IA solo lee→Propuesta revisada→Tu «sí»→El bot ejecuta y registra
1

Acceso con lista

Solo pueden entrar los números incluidos en la lista. Lista vacía = nadie entra; el bot solo registra quién lo intentó.

2

Visita sin tocar nada

La IA puede revisar, pero solo dentro de una carpeta de trabajo, y nunca ve claves, SSH ni datos de inicio de sesión.

3

Presupuesto antes del trabajo

Para cambiar algo, la IA solo escribe lo que haría. El bot lo compara con una lista breve de comandos permitidos.

4

Tú das la aprobación

Un «sí» claro es lo único que lo autoriza, y tiene una validez de 10 minutos. El bot ejecuta exactamente lo que mostró.

5

Registro de actividad

Cada pedido, propuesta, «sí» y resultado se convierte en una línea de auditoria.jsonl, sin el token.

⚠️ El fallo que corrige esta guía

Claude Code suma los permisos de su propio settings.json a los del bot. Lo probamos: en una máquina donde rm estaba permitido, el pedido «borra la carpeta logs» la borró de verdad, aunque el bot pidiera «solo lectura». En la etapa 5, el bot empieza a ignorar esos ajustes (--setting-sources ""), y la prueba final coloca una trampa de ese tipo a propósito para demostrar que no funciona.

1

Preparar la VPS y Claude Code

Conéctate con un usuario común (no root), instala Claude Code e inicia sesión con tu suscripción, no con una clave de API. Después crea la carpeta del bot y descarga el Telegram falso.

python3 --version
curl -fsSL https://claude.ai/install.sh | bash
claude                         # /login con la cuenta de la suscripción → /exit
env | grep -c ANTHROPIC_API_KEY
claude -p "responda só: ok" --model haiku
mkdir -p ~/kits/telegram-vps-remoto/ferramentas ~/kits/telegram-vps-remoto/testes
cd ~/kits/telegram-vps-remoto
curl -fsSLo ferramentas/telegram_falso.py https://raw.githubusercontent.com/inematds/telegram-vps-passo-a-passo/main/ferramentas/telegram_falso.py

2

Crear el bot con BotFather y guardar el token

En Telegram, habla con @BotFather, envía /newbot y guarda el token en un .env que solo tú puedas leer. El token es la contraseña del bot: nunca va a git, a una captura de pantalla ni a un video. El primer bot.py solo se presenta a Telegram.

cat > .env <<'EOF'
TELEGRAM_BOT_TOKEN=cole_o_token_aqui
DONOS=
EOF
chmod 600 .env
# terminal 1 (déjalo corriendo): el Telegram falso
python3 ferramentas/telegram_falso.py servidor
# terminal 2: el bot, apuntando al falso
TELEGRAM_API=http://127.0.0.1:8081 TELEGRAM_BOT_TOKEN=123:falso python3 bot.py
Salida esperada 
conectado como @bot_falso_bot

4

Solo el propietario puede hablar con el bot

Cualquiera puede encontrar tu bot. La lista DONOS cierra el acceso: si está vacía, nadie puede entrar, y el bot muestra el número de quien lo intentó. Así descubres tu número en el bot real.

TELEGRAM_API=http://127.0.0.1:8081 TELEGRAM_BOT_TOKEN=123:falso DONOS= python3 bot.py
python3 ferramentas/telegram_falso.py fala --de 111 "oi"
# detén el bot y córrelo con DONOS=111
python3 ferramentas/telegram_falso.py fala --de 111 "/start"

bot → Pronto. Peça o que quiser na VPS. Antes de mudar qualquer coisa eu pergunto.

5

El pedido llega a Claude Code, solo para leer

Ahora el pedido se envía a claude -p, y las barreras están en el propio comando:

  • la IA solo puede usar herramientas de lectura;
  • las claves, SSH, los datos de inicio de sesión y cualquier escritura están bloqueados;
  • lo que no se autorizó se rechaza sin preguntar;
  • se ignoran tus ajustes personales de Claude Code;
  • todo se ejecuta dentro de area/.
mkdir -p area/logs && for i in 1 2 3; do seq 1000 > area/logs/app-$i.log; done
TELEGRAM_API=http://127.0.0.1:8081 TELEGRAM_BOT_TOKEN=123:falso DONOS=111 python3 bot.py
python3 ferramentas/telegram_falso.py fala --de 111 "quanto espaço livre tem no disco?"
python3 ferramentas/telegram_falso.py fala --de 111 "apaga a pasta logs"
ls area/logs | wc -l

6

La IA solo propone; el bot revisa

La IA empieza a responder en un formato fijo: la respuesta y, si hace falta cambiar algo, los comandos exactos. El bot revisa sin IA:

  • solo comandos simples (rm, mv, cp, mkdir, touch, gzip, gunzip, tar);
  • solo opciones de una lista breve;
  • ningún carácter que encadene o desvíe comandos;
  • todas las rutas dentro del área.
TELEGRAM_BOT_TOKEN=x python3 -c "
import bot
for p in ['rm -r logs', 'rm -r ~/.ssh', 'rm -r logs; reboot', 'tar -C/tmp -xf a.tar', 'cp --target-directory=/tmp logs', 'rm -rf .']:
    try: bot.validar(p); print('aceito ', p)
    except ValueError as e: print('recusa ', p, '-', e)
"
Salida esperada 
aceito  rm -r logs
recusa  rm -r ~/.ssh - passos com caractere proibido
recusa  rm -r logs; reboot - passos com caractere proibido
recusa  tar -C/tmp -xf a.tar - opção não permitida: -C/tmp
recusa  cp --target-directory=/tmp logs - opção não permitida: --target-directory=/tmp
recusa  rm -rf . - não posso apagar ou mover a própria área

En el bot, «borra la carpeta logs» ahora devuelve Vou fazer: …, Comandos: rm -r logs y Confirma? (sim/não), y todavía no se borra nada.

Archivo de esta etapa: etapas/06-proposta-e-validador/bot.py

7

Después del «sí», el bot es quien ejecuta

Solo confirman sim, s, confirmo, confirma, yes (incluso en una frase, como «sim, pode apagar») o pode, ok, manda, faz por sí solos. Un mensaje con «?» nunca confirma: «pode listar antes?» no borra nada. El pedido vale por 10 minutos y se revisa un paquete .tar antes de abrirlo.

python3 ferramentas/telegram_falso.py fala --de 111 "apaga a pasta logs"
python3 ferramentas/telegram_falso.py fala --de 111 "não"
python3 ferramentas/telegram_falso.py fala --de 111 "apaga a pasta logs"
python3 ferramentas/telegram_falso.py fala --de 111 "sim"
ls area
Salida esperada 
bot → … Confirma? (sim/não)
bot → Cancelado. Nada foi mudado.
bot → … Confirma? (sim/não)
bot → Feito:
      rm -r logs → ok

Preguntas

Preguntas frecuentes

Lo que suele surgir antes de empezar.

¿Necesito saber programar?

Te ayuda saber copiar y pegar en la terminal. El código está incluido en cada etapa, junto con el archivo listo para consultar. Si te atascas, el README tiene un pedido listo para que Claude Code te acompañe, etapa por etapa.

¿Cuesta algo además de la suscripción?

No. El bot usa Claude Code, que ya pagas, y solo la biblioteca estándar de Python. Telegram es gratis. Solo necesitas una VPS.

¿La IA puede borrar algo sin que se lo pida?

No. Solo tiene herramientas de lectura, está limitada a una carpeta y nunca ve las claves. Para cambiar algo, solo redacta una propuesta. El bot es quien ejecuta después de tu «sí», y solo usa comandos simples dentro de la carpeta de trabajo.

¿Qué pasa si otra persona encuentra mi bot?

Recibe «Este bot é privado.» y su número queda registrado. Solo los números de la lista DONOS pueden hablar con el bot.

Ya tengo el kit listo. ¿Para qué necesito la guía?

Para entenderlo y poder cambiarlo. Si lo configuras tú mismo, sabrás dónde está cada barrera y por qué existe, y podrás agregar comandos o carpetas de forma segura.

¿Funciona sin VPS, en mi computadora?

Las pruebas con el Telegram falso se ejecutan en cualquier Linux con Python 3 y Claude Code. El bot real está pensado para funcionar en una VPS.
